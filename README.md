# scRNAseq_bovine_lactation_monocyte_crosstalk

# 🧬 Classical monocytes-driven inflammatory circuits dictate immune-epithelial crosstalk during lactation

This repository contains the analysis code and workflows for our study:

**"Classical monocytes-driven inflammatory circuits dictate immune-epithelial crosstalk during lactation"**  

## **1. Introduction**

As part of the immune–lactation crosstalk study, we describe a comprehensive single-cell transcriptomic atlas of peripheral blood mononuclear cells (PBMCs) from dairy cattle with divergent milk yield across the lactation cycle. This atlas, generated by single-cell RNA sequencing, identifies 10 distinct immune cell types and reveals cell-type-specific transcriptional reprogramming associated with lactational performance and physiological stage. Integrative analysis with milk yield genome-wide association study (GWAS) statistics pinpoints classical monocytes as the primary cellular hub genetically linked to lactational performance, unveiling a TNF/IL-1β-driven inflammatory program that is uniquely exacerbated by an IFN-γ-responsive signature in low-yield cows. In vitro co-culture experiments demonstrate that IFN-γ-stimulated monocytes from low-yield cows suppress key lactogenic genes in mammary epithelial cells via NF-κB pathway hyperactivation and SOCS3 upregulation. Cross-species comparative analysis reveals highly conserved monocyte–MEC communication networks between bovines and humans, establishing the TNF axis as an evolutionarily conserved module of immune–epithelial crosstalk. This atlas will serve as a key resource for dairy cattle immunology, lactation biology, and comparative medicine, offering a single-cell framework for understanding and improving polygenic production traits.
